## Brand & Style

This design system embodies a high-performance, developer-first aesthetic built for reliability, technical precision, and deep focus. The tone is authoritative, utilitarian, and calm, drawing from dark-mode-native tooling and modern engineering platforms. 

The visual style merges a **Minimalism** framework with functional **High-Contrast** feedback states, relying on a deeply immersive dark canvas, razor-sharp structural lines, and purposeful flashes of chromatic illumination to guide developer workflows without visual fatigue.

## Colors

The color palette is engineered specifically for extended coding sessions and complex data review in dark environments. 

- **Canvas & Surfaces:** Built on a deep void background (`#0B0F17`) layered with elevated slate panels (`#111827`) to establish clear hierarchy between the workspace and containers.
- **Borders & Dividers:** Subtle, low-contrast structural dividers (`#1E293B` and `#1F2937`) define layout boundaries without visual clutter.
- **Typography Tints:** High-legibility crisp white (`#F9FAFB`) anchors primary reading, supported by muted slate (`#9CA3AF`) for secondary metadata and inactive states.
- **Brand Accents:** Electric Indigo (`#6366F1`) drives primary interactive elements and actions, while Cyber Emerald (`#10B981`) serves as the definitive signal for successful verification and passing test suites.
- **Severity Spectrum:** Purpose-built semantic indicators map directly to developer risk levels: Critical (`#EF4444`), High (`#F97316`), Medium (`#F59E0B`), and Low (`#38BDF8`).

## Typography

The type system pairs **Inter** for crisp, highly readable UI chrome with **JetBrains Mono** for raw code blocks, file paths, diffs, and numeric tokens. 

Ensure line heights remain tight to support dense information architecture without sacrificing scanning speed. Monospaced elements must always maintain strict character alignment across diff additions and deletions.

## Layout & Spacing

The layout model relies on a **Fixed grid** philosophy optimized for multi-pane developer environments (e.g., file trees, editor panes, and AI review sidebars). 

Spacing operates on a strict 4px/8px baseline rhythm. Gutters remain compact (`1rem`) to maximize screen real estate for dense code review modules, while outer canvas margins scale fluidly down to `1rem` on mobile and tablet form factors. Content reflow rules dictate that sidebars collapse into drawer overlays below the 1024px breakpoint.

## Elevation & Depth

Depth is conveyed through **Low-contrast outlines** and subtle tonal stacking rather than heavy drop shadows. 

Surfaces step forward purely through incremental lightness shifts between canvas (`#0B0F17`) and elevated panels (`#111827`), bound by razor-thin, ghost borders (`#1E293B`). Interactive elements reveal state changes exclusively via border luminance shifts and internal fill highlights rather than elevation displacement.

## Shapes

The shape language uses a **Soft** roundedness configuration. 

Containers, panels, and input fields feature restrained corner radii (`0.25rem` to `0.5rem`) to maintain a precise, engineered feel without soft consumer-grade pill shapes. Buttons and badges use crisp, controlled rounding to align with modern IDE design paradigms.

## Components

- **Buttons:** Primary actions utilize Electric Indigo (`#6366F1`) with subtle hover state brightening; secondary actions employ ghost borders on slate panels. Verification actions leverage Cyber Emerald (`#10B981`).
- **Chips & Badges:** Utilize monospaced typography with tight padding. Severity indicators map directly to semantic colors with low-opacity background tints.
- **Inputs & Search:** Rendered with solid `#111827` background fills, `#1E293B` borders, and focus rings tinted in Electric Indigo.
- **Code Blocks & Diffs:** Built on JetBrains Mono, featuring inline line-number columns, soft red/green background highlights for additions and deletions, and sticky header bars for file paths.
- **Cards & Panels:** Elevated containers with 1px structural borders, designed to house collapsible metadata, test summaries, and AI agent output logs.
